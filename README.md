# trytatami.com

The website for Tatami, the app for learning the judo syllabus belt by belt: landing page, Privacy Policy, Terms of Use and Support. Static HTML and CSS served by GitHub Pages.

The look follows the app and its App Store art: cream and charcoal, misty mountains (`assets/mountains.svg` and `assets/mountains-night.svg`, drawn from the app's `MountainRange` recipe), and a belt colour on the second line of each headline. App screenshots live in `assets/screens/`, the link preview in `assets/og.png`. The App Store badge is Apple's official artwork, embedded from Apple's marketing toolbox.
